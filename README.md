# תקציר – אפליקציית חדשות אישית ל-Android

אפליקציה שמרכזת כל יום את הכתבות החשובות בחמישה נושאים (פוליטיקה, כלכלה, סייבר, ביטחון, גאופוליטיקה), בלי עומס.

## מה יש בה
- **טאבים לפי נושא**, ובכל אחד רשימה מצומצמת של כתבות: כותרת, סיכום קצר, מקור ושעה. כתבות חשובות במיוחד מסומנות בנקודה קטנה.
- **השבוע / היום** – מעבר בין כל השבוע (מחולק לימים) לבין היום בלבד. כתבות שלא נקראו נמחקות אחרי שבוע.
- **לחיצה** פותחת את הכתבה באתר. **אייקון הספר** (או לחיצה ארוכה) פותח **קריאה מהירה** בתוך האפליקציה.
- **נקרא = עובר להיסטוריה.** פתיחת כתבה או החלקה עליה מסמנת אותה כנקראה. בהיסטוריה, החלקה מחזירה אותה לרשימה.
- **מדדים בטאב כלכלה**: S&P 500, NASDAQ, ת"א 35.
- **התראות**: לכל נושא בוחרים שעות (למשל 08:00 ו-20:00). בכל שעה כזו האפליקציה בודקת, ושולחת התראה רק אם יש כתבה חשובה (דירוג 7 ומעלה) שעוד לא התריעה עליה.

## איך נבחרות הכתבות
1. **מקורות איכותיים בלבד** – כ-30 פידים נבחרים בעברית ובאנגלית (גלובס, ynet, Times of Israel, BBC, The Record, BleepingComputer, Krebs, Defense News, Foreign Policy ועוד). הרשימה המלאה ב-`Sources.kt`.
2. **דירוג ראשוני** – סיפור שמכוסה בכמה מקורות שונים מקבל עדיפות; מקורות איכותיים יותר שוקלים יותר; כתבות טריות קודמות; מילות מפתח של הנושא מעלות רלוונטיות; פודקאסטים, חידונים ובלוגים חיים יורדים.
3. **עורך AI (Claude)** – מקבל את 40 המועמדים המובילים, בוחר רק מה שבאמת חשוב או מעשיר, ממזג כפילויות, ומדרג 1–10. לכל כתבה הוא כותב כותרת וסיכום של 2–3 משפטים בעברית.
4. **תקרה יומית** – עד 7 כתבות ביום לכל נושא (ניתן לשנות בין 4 ל-12). תוספת של עד 2 כתבות מותרת רק לאירוע חריג (דירוג 9+).

בלי מפתח API האפליקציה עובדת, עם הדירוג הראשוני ותקציר המקור (לרוב באנגלית בכתבות זרות).

## התקנה על הטלפון

### אפשרות א': בנייה אוטומטית ב-GitHub (בלי להתקין כלום)
1. צור repository חדש ב-GitHub והעלה אליו את כל תוכן התיקייה.
2. בלשונית **Actions** תרוץ אוטומטית הבנייה "Build APK" (אפשר גם להפעיל ידנית).
3. בסיום, הורד את `taktzir-apk` מתחתית עמוד הריצה, חלץ את קובץ ה-APK והעבר אותו לטלפון.
4. בטלפון: פתח את הקובץ ואשר "התקנה ממקורות לא ידועים".

### אפשרות ב': Android Studio
פתח את התיקייה ב-Android Studio, חבר את הטלפון (עם USB debugging) ולחץ Run.

## הגדרה ראשונית
1. **הגדרות ← סיכומים ודירוג בעזרת AI**: הדבק מפתח API מ-console.anthropic.com. המודל ברירת המחדל הוא `claude-haiku-5-5` (מהיר וזול), וניתן לשנות אותו תחת "מתקדם".
2. **הגדרות ← התראות**: הפעל את הנושאים הרצויים ובחר שעות.
3. משיכה למטה במסך הראשי מרעננת. ברקע האפליקציה מתרעננת לבד כל כ-4 שעות.

## הערות
- המפתח נשמר מקומית במכשיר בלבד, ונשלח רק ל-API של Anthropic.
- שעות ההתראה מדויקות בטווח של דקות ספורות, כי Android מאחד משימות רקע לחיסכון בסוללה.
- קריאה מהירה לא תעבוד באתרים עם חומת תשלום. במקרה כזה מוצג הסיכום וכפתור לאתר.
- כדי להוסיף או להסיר מקור, ערוך את `app/src/main/java/com/taktzir/news/data/Sources.kt`.

## מבנה הקוד
```
data/    Category, Sources, מסד נתונים (Room), הגדרות (DataStore)
net/     קריאת RSS, עורך ה-AI, קריאה מהירה, מדדי שוק
domain/  Ranker (דירוג ואשכול), NewsRepository (רענון, תקרה יומית, ניקוי)
work/    רענון ברקע והתראות מתוזמנות (WorkManager)
ui/      מסכים ב-Jetpack Compose: ראשי, קריאה מהירה, היסטוריה, הגדרות
```
